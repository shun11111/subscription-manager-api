# ダッシュボード

## 概要
サブスクリプション管理のダッシュボード画面。サマリー情報、次回課金日が近いサブスクリプション、サブスクリプション一覧を表示します。

## API仕様

### エンドポイント
既存のサブスクリプション管理APIを使用します。

#### GET /subscriptions
- **説明**: サブスクリプション一覧取得（ダッシュボードで使用）
- **認証**: 必要 (Bearer Token)
- **リクエスト**: なし
- **レスポンス**: Subscription[]
- **エラー**: 401 (認証エラー)

詳細は [`subscriptions.md`](./subscriptions.md) を参照してください。

## フロント仕様

### 画面構成
- **ページパス**: `/dashboard`
- **レイアウト**: ダッシュボード（カスタムレイアウト）
- **認証**: 必要
- **ナビゲーション**: メニューに表示する（メイン画面）

### UI要件

#### サマリーカード（上部）
以下の5つのサマリーカードを表示：
1. **総サブスク数**: 登録されているサブスクリプションの総数
2. **月額合計**: `billing_cycle` が `monthly` のサブスクリプションの合計金額
3. **年額合計（月換算）**: `billing_cycle` が `yearly` のサブスクリプションの合計金額を12で割った値
4. **今月の支払い予定額**: 今月中に課金予定のサブスクリプションの合計金額
5. **次回課金日が近いサブスク数**: 7日以内に次回課金日が来るサブスクリプションの数

#### 次回課金日が近いサブスクリプション（優先表示セクション）
- 7日以内に次回課金日が来るサブスクリプションをカード形式で表示
- 日付順（昇順）でソート
- 各カードに以下を表示：
  - サービス名（`name`）
  - 金額（`price`）
  - 次回課金日（`next_billing_date`）
  - 課金サイクル（`billing_cycle`）

#### サブスクリプション一覧
- テーブル形式で表示
- カラム:
  - サービス名（`name`）
  - 金額（`price`）- フォーマット: `¥{price}`
  - 次回課金日（`next_billing_date`）- フォーマット: `YYYY/MM/DD`
  - 課金サイクル（`billing_cycle`）- 表示: `月額` / `年額`
  - アクション（編集/削除ボタン）
- デフォルトソート: 次回課金日順（昇順）
- 行クリックで詳細画面に遷移（将来実装）

#### クイックアクション
- 「新規サブスク追加」ボタン（右上）
- 検索バー（オプション、将来実装）
- フィルター（オプション、将来実装）

### ルーティング
- ダッシュボード: `/dashboard`
- ログイン成功後は `/dashboard` にリダイレクト

### データ処理ロジック

#### サマリー計算
- **総サブスク数**: `subscriptions.length`
- **月額合計**: `subscriptions.filter(s => s.billing_cycle === 'monthly').reduce((sum, s) => sum + s.price, 0)`
- **年額合計（月換算）**: `subscriptions.filter(s => s.billing_cycle === 'yearly').reduce((sum, s) => sum + s.price, 0) / 12`
- **今月の支払い予定額**: 今月中に `next_billing_date` が来るサブスクリプションの合計金額
- **次回課金日が近いサブスク数**: 7日以内に `next_billing_date` が来るサブスクリプションの数

#### 次回課金日が近いサブスクリプション
- 現在日から7日以内に `next_billing_date` が来るサブスクリプションをフィルタ
- `next_billing_date` でソート（昇順）

#### サブスクリプション一覧
- すべてのサブスクリプションを表示
- デフォルトで `next_billing_date` でソート（昇順）
