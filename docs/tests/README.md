# テストケース

このディレクトリには、各APIエンドポイントのテストケースが含まれています。

## テストケースの形式

各画面用のテストケースは、以下のいずれかの形式で作成されます：

- `{画面名}_test.sh` - 実行可能なシェルスクリプト形式
- `{画面名}_test.md` - Markdown形式（コマンド例と説明）

## テストケースの実行方法

### シェルスクリプト形式の場合

```bash
# 実行権限を付与
chmod +x docs/tests/{画面名}_test.sh

# 実行
./docs/tests/{画面名}_test.sh
```

### 前提条件

- サーバーが起動していること（`go run ./cmd/api/main.go`）
- 環境変数（`.env`）が正しく設定されていること
- データベースにマイグレーションが実行されていること

## テストケースの追加

新しい画面を追加した際は、`@cursor-instruction.md` の指示に従って、自動的にテストケースが生成されます。

詳細は [`../API_TESTING.md`](../API_TESTING.md) を参照してください。
